# IHRS — Interoperable Hospital Record Sharing System

**IHRS** is a web-based healthcare platform designed to enable secure and controlled sharing of patient health records between hospitals.

The system focuses on **patient privacy, consent, security, and accountability**, allowing authorized healthcare professionals to access records when they have the required permissions.

### ✨ Key Features

* 🆔 Unique National Health ID (NHID) for patients
* 🏥 Secure cross-hospital health record sharing
* 🔐 AES-128 and RSA-512 based encryption
* 👥 Role-Based Access Control (RBAC)
* ✅ Patient consent management
* 🚨 Emergency access mechanism
* 📋 Tamper-evident audit logs using hash chains
* 🩺 NEWS2-based clinical risk scoring
* 🌱 Lifestyle recommendations
* 🔗 Peer-hospital communication

### 🛠️ Tech Stack

**Backend:** Django, Django REST Framework, PostgreSQL
**Frontend:** React, Vite, Tailwind CSS, Axios
**Security:** AES-128, RSA-512, RBAC, SHA-256 Hash Chain
